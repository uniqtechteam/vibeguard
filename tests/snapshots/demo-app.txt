CRITICAL
  PAY-001 Stripe webhook without signature check
    app/api/stripe/webhook/route.ts:6
    > if (event.type === 'checkout.session.completed') {
    Why: This webhook acts on Stripe events without checking Stripe's signature, so anyone can send a fake "payment succeeded" and get the product for free.
    Fix: Read the raw body and call `stripe.webhooks.constructEvent(body, signature, webhookSecret)` before trusting the event.

  SEC-002 Supabase service-role key in browser code
    components/AdminTable.tsx:4
    > const admin = createClient(process.env.NEXT_PUBLIC_SUPABASE_URL!, process.env.SUPABASE_SERVICE_ROLE_KEY!)
    Why: This code runs in the browser, and the service-role key skips every Row Level Security rule, so anyone can read and change all of your data with it.
    Fix: Use the anon key in the browser and move anything that needs the service-role key into a server route or edge function.

  DB-001 Supabase table without Row Level Security

    > create table profiles (
    Why: Table `profiles` has no Row Level Security, so anyone with your public anon key can read and change every row.
