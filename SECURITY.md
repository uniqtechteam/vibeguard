# Security

If you find a security problem in vibeguard itself (for example a way to make it print a full secret,
or a crafted file that makes it hang), please report it privately through
[GitHub security advisories](https://github.com/uniqtechteam/vibeguard/security/advisories/new) rather than
a public issue. We answer within 14 days, usually much sooner.

vibeguard never sends code or results anywhere; if you see it touch the network, that is a bug worth
reporting too.
